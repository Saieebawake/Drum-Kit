# 🥁 Drum Kit

A simple and interactive **Drum Kit Web Project** built using **HTML, CSS, and JavaScript**.

Press the specified keyboard keys to play different drum sounds. The corresponding key also gets a visual animation when pressed.

## 🚀 Features

- 🎵 Play different drum sounds using keyboard keys
- ⌨️ Keyboard-based controls
- ✨ Visual animation when a key is pressed
- 🔊 Uses HTML5 Audio to play sounds
- 🎨 Simple and responsive visual design
- ⚡ Built with vanilla JavaScript — no external frameworks

## 🎹 Keyboard Controls

| Key | Sound |
|-----|-------|
| **A** | Clap |
| **S** | Hi-Hat |
| **D** | Kick |
| **F** | Open Hat |
| **G** | Boom |
| **H** | Ride |
| **J** | Snare |
| **K** | Tom |
| **L** | Tink |

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layout, animations, and background
- **JavaScript** – Keyboard events, audio playback, and DOM manipulation
- **HTML5 Audio API** – Playing drum sounds

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/drum-kit.git
```

2. Open the project folder in VS Code.

3. Make sure the `sounds` folder is present inside the project folder.

4. Open `index.html` in your browser.

5. Press **A, S, D, F, G, H, J, K, or L** to play the corresponding drum sound.
